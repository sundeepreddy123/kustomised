🧩 Overview

This repository contains Kubernetes manifests to deploy a containerized microservice application using:

Kubernetes (K8s) for orchestration

Istio Service Mesh for traffic management

NodePort Service (32700) for external access

Horizontal Pod Autoscaler (HPA) for scalability

Kustomize for environment-based configuration

GitOps-ready structure (Argo CD compatible)

The application is designed to be scalable, observable, and production-ready.
